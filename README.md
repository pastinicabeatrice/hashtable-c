# Tabelă de dispersie - comenzi

Tabelă de dispersie cu rezolvarea coliziunilor prin înlănțuire (liste simplu înlănțuite), cu cheia `idComanda`.

## Funcționalități

- crearea tabelei din `comenzi.txt`
- traversarea tabelei
- numărul de comenzi cu livrare la o dată dată
- ștergerea comenzilor deja livrate față de data curentă
- extragerea comenzilor unui client într-o listă separată
- dezalocarea memoriei

## Structura de date

`Comanda`: id, data lansării, data de livrare programată, nume client, suma de plată.

## Rulare

Se deschide `hashtable.sln` în Visual Studio. Fișierul `comenzi.txt` trebuie să fie în directorul de lucru.
